# 🚗 AutoNest
### Find your drive. Choose your journey.

AutoNest is a responsive automobile website designed to help users explore cars, discover vehicles based on their preferences, compare specifications, and connect with the team.

The project is developed using **HTML, CSS, and JavaScript**, focusing on a clean user interface, responsive design, and interactive functionality.

---

## 📌 Project Overview

AutoNest provides a simple and user-friendly platform for exploring cars and comparing different models. The website is designed with a modern automotive theme and provides essential features for users to make informed decisions.

## ✨ Features

### 🏠 Home Page
- Modern landing page
- Navigation bar
- Hero section
- Featured cars
- Popular brands section
- Budget-based car recommendations
- Why Choose AutoNest section
- Call-to-action section

### 🚘 Explore Cars
- Browse available cars
- Search cars by name
- Filter by brand
- Filter by fuel type
- Filter by body type
- Filter by price range
- Reset filters

### ⚖️ Compare Cars
- Select cars for comparison
- Add cars to comparison
- Change selected cars
- Remove cars
- Dynamically generated comparison table
- Compare car specifications

### 🚗 Car Details
- View individual car details
- Access car information through the Explore Cars page
- Detailed vehicle information
- Navigation between pages

### 📩 Contact Us
- Contact form
- Form validation
- Character counter
- Consent checkbox
- Submission success message
- FAQ section

## 🤝 Collaboration

This project is developed collaboratively using Git and GitHub.

### Workflow

1. Pull the latest changes from `main`.
2. Create a feature branch for your assigned page.
3. Develop your feature.
4. Push your branch to GitHub.
5. Create a Pull Request targeting `main`.
6. Changes are reviewed before merging.

### Branch Naming Convention

```text
feature/home-page
feature/cars-page
feature/car-details
feature/compare-page
feature/contact-page
```
